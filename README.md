# Healthcare Management System

The Healthcare Management System is a web-based application developed using Next.js, React, TypeScript, Appwrite and Tailwind CSS with real-time SMS Notifications designed to streamline the checkup process. It allows patients to easily register, personal information, medical history, identification, easy appointment scheduling with your preferred doctor, confirmation screen upon booking and a comprehensive admin panel for scheduling and canceling appointments with SMS Notification. The system provides features such as authentication, listing upcoming appointments, managing appointments, and implementing search functionality. The application is responsive, ensuring a seamless experience across different devices.

## Tech Stack

- **Next.js13:** A React framework for building server-side rendered and statically generated web applications.
- **React:** A JavaScript library for building user interfaces.
- **TypeScript:** A statically typed superset of JavaScript that enhances code quality and maintainability.
- **Appwrite:** open-source backend-as-a-service (BaaS) platform designed to simplify and accelerate the development of web and mobile applications by providing a set of pre-built backend services such as     
  authentication, databases, file storage, and real-time functionalities
- **Tailwind CSS:** A utility-first CSS framework that provides pre-defined styling classes and components.
